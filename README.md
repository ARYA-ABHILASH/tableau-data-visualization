# Retail Sales Analysis — Tableau

## Project Overview
This project focuses on analyzing retail sales and profitability using Tableau. The dashboard is designed to explore sales trends, product performance, customer segments, and regional patterns through data visualization.

## Tools Used
- Tableau
- Data visualization
- Interactive dashboards

## Project Objectives
- Analyze sales and profit performance.
- Compare sales across regions and categories.
- Explore monthly sales trends.
- Identify top-performing products.
- Visualize sales distribution across states and customer segments.

## Key Learnings
- Tableau dashboard development
- Data visualization and storytelling
- Interactive filters
- Calculated fields and KPI design
